# Global Olympic Sports Performance Analysis

## Project Overview
This project analyzes historical Olympic sports performance using Tableau.

## Objectives
- Analyze medal-winning records across countries.
- Compare medal counts across different sports.
- Identify Olympic medal trends over the years.
- Present insights through interactive Tableau visualizations.

## Tools & Technologies
- Tableau Public
- Microsoft Excel / CSV
- GitHub

## Dataset
Olympic athlete events dataset (1896–2016).

## Dashboard Visualizations
1. Medal Count by Country
2. Medal Count by Sport
3. Olympic Medal Trends by Year

## Project Outcome
An interactive Tableau dashboard that helps explore Olympic medal records and historical sports performance.
